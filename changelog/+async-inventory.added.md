Load the inventory from a running event loop with `await AInitNornir(...)`. `InfrahubInventory` loads the inventory with the asynchronous Infrahub client, and the hosts hold an `InfrahubNode`. Run the new asynchronous tasks `aget_artifact`, `agenerate_artifacts`, `aregenerate_host_artifact`, `aupload_file_object` and `adownload_file_object` on these hosts with `Nornir.arun` and the `asyncio` runner. `InfrahubInventory` is now also registered in the `nornir.plugins.capability_inventory` entry-point group, which requires a Nornir release with that registry; it stays in `nornir.plugins.inventory` for older Nornir releases.
