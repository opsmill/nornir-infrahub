`InfrahubInventory` is registered in the `nornir.plugins.capability_inventory` entry-point group instead of `nornir.plugins.inventory`, and requires a Nornir release with that registry. Remove any `InventoryPluginRegister.register("InfrahubInventory", InfrahubInventory)` call: Nornir raises `InventoryPluginAmbiguousError` when one name is in both registries. The plugin now fetches the host node schema when it loads the inventory instead of when it is created, so mapping errors are raised by `load` or `aload`. A synchronous task raises `TypeError` on a host loaded with `AInitNornir`, and an asynchronous task raises `TypeError` on a host loaded with `InitNornir`.
