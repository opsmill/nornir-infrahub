Read typed task results with Nornir 3.7.0b1. Each task now declares the type of `Result.result`, so a type checker and an editor know the type of `multi.result` after `nr.run()` or `await nr.arun()`: `None` for `generate_artifacts` and `regenerate_host_artifact`, `str` for `upload_file_object`, and `FileObjectDownload` for `download_file_object`. The asynchronous tasks declare the same types. `download_file_object` and `adownload_file_object` now return the file content and metadata as a `FileObjectDownload` model in `Result.result`, which was `None` before. The same fields stay available as attributes of the `Result`.
