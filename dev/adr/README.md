# Architecture Decision Records

Point-in-time decisions recorded in the [MADR](https://adr.github.io/madr/) format.

Name each record `nnnn-title.md`:

- `nnnn` — a zero-padded **4-digit** sequence (`0001`, `0002`, …)
- `title` — a lowercase, kebab-case summary
- **no** `adr-`/`ADR-` prefix

Example: `0001-use-uv-for-python.md`
